# Easy BITX documentation

This directory contains the Easy BITX construction and reference documents archived with the project.

## Local manuals

| File | Subject |
| --- | --- |
| [Building-Easy-Bitx-Ver-1.pdf](Building-Easy-Bitx-Ver-1.pdf) | Easy BITX Version 1 construction manual |
| [Easy-Bitx-Coils.pdf](Easy-Bitx-Coils.pdf) | Coil-related reference |
| [AGC.pdf](AGC.pdf) | Automatic gain control (AGC) reference |
| [Voltage-Readings.pdf](Voltage-Readings.pdf) | Voltage measurements/reference |
| [Boxing-Easy-Bitx.pdf](Boxing-Easy-Bitx.pdf) | Boxing/enclosure reference |

These descriptions identify the documents by their titles. The archive does not establish that every document applies to every Easy BITX hardware revision.

## Related hardware files

The [hardware directory](../hardware/README.md) contains the Easy BITX Version 2.0 complete and sectional circuit schematics, PCB reference drawings, and Excel bill of materials.

**Revision note:** The Version 1 construction manual and Version 2.0 drawings should be cross-checked before using part values, connections or alignment procedures interchangeably.
