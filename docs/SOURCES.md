# Original document sources

The following manuals are linked, not republished in this repository:

1. [Easy BITX Version 1 construction manual](https://amateurradiokits.in/wp-content/uploads/2020/04/Building-Easy-Bitx-Ver-1.pdf) — circuit schematics, assembly and alignment.
2. [VU3GAO firmware guide](https://amateurradiokits.in/wp-content/uploads/2021/10/Easy_BITX_Firmware_vu3gao.pdf) — firmware installation and configuration; verify hardware revision.
3. [Easy BITX coil winding guide](https://amateurradiokits.in/wp-content/uploads/2021/09/Easy-Bitx-Coils1.pdf) — toroids/RFC reference.

Run `python3 scripts/fetch_sources.py` to download local copies.

Copyright and redistribution terms for these documents have not been independently verified. Links are provided for reference.
