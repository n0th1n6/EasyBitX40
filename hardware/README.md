These PDFs are reference drawings, not native EDA source files or verified manufacturing Gerbers.

## Firmware compatibility

The repository includes [firmware v1.3](../firmware/EasyBitx_v1.3.ino) and [firmware v1.5](../firmware/EasyBitx_vu3gao_v1.5.ino) for an Arduino Nano / Si5351 VFO/BFO controller. Verify the board revision, wiring, intermediate frequency and BFO calibration before selecting a firmware version.

Original materials are attributed to their respective creators. Availability of the drawings does not establish an open hardware license.
